# Bugging you
A simple note taking PWA. It allows you to make notes, which appear with your device notifications.

## Features

- Maintains a list of short notes
- Each note can be chosen to display as a notification
- Notes are editable and removable
- Mobile-first: Designed for your smart-phone in mind
- Private: Everything is stored locally on your device, no data leaves it
- PWA: Pin the site to your home screen and take quick notes with ease

## Technicals

- Developed in HTML+CSS+Javascript, no franeworks, no dependencies, just simplicity
- All data stored in local storage, nothing sent over the network
- Deployed on Vercel
